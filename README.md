# WarrantWorks TN

This repository holds two things:

- **`harmonizer/`**: the working local program. It harmonizes court forms: you upload versions of a form, compare them line by line with sources linked, a person reconciles each difference, it generates a uniform master that keeps the familiar layout, exports real PDF/DOCX/TXT files that are verified on re-read, and it keeps a durable revision history. Start with [`harmonizer/README.md`](harmonizer/README.md).
- **`warrantworks-tn-prod/`**: the February 2026 Next.js demonstration interface. It returns a hard-coded mock analysis and is kept only for reference.

Use blank or synthetic forms. Recovered AOC forms are historical until they have been verified against current official sources.
